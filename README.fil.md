Mobile app para sa paghatak ng sasakyan.

Tumatawag ang shoulder sa mga kalapit na talyer, at hawak nito ang tinatayang oras ng dating at ang presyo. Hindi ginagalaw ang mga dolyar na sakop ng seguro.

Nasa [`src/`](src/) ang web app. Nasa [`ios/`](ios/) ang iOS app.

Paano i-update ang mga salin na ito: [`docs/TRANSLATIONS.md`](docs/TRANSLATIONS.md).
