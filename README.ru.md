Мобильное приложение для эвакуации автомобилей.

shoulder звонит в ближайшие мастерские, затем удерживает расчётное время прибытия и цену. Доллары, покрытые страховкой, не затрагиваются.

Веб-приложение находится в [`src/`](src/). Приложение для iOS — в [`ios/`](ios/).
